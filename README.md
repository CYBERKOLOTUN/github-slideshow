# Лист — веб-блокнот

Готовая статическая сборка отдельного приложения. Содержит только код и примеры заметок. Пользовательские заметки хранятся в браузере посетителя, в GitHub не отправляются.

Для включения сайта: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: notebook-site → /(root) → Save.

Эта ветка создана отдельно: main, master и исходная презентация не изменены. Если GitHub Pages уже обслуживает другой сайт, смена его ветки изменит опубликованный сайт.
